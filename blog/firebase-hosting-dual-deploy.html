Firebase Hosting + GitHub Pages: Ek Codebase, Do Ghar

Kyun do jagah?

November 2026 ka sabaq: ek platform par sab kuch nahi. GitHub account suspend ho sakta hai, Vercel bill 402 de sakta hai. Isliye site ka source git me, aur deploy do independent hosts par.

Setup (3 files)

FileKaam
firebase.jsonpublic: ".", ignore list, cache + security headers
.firebasercdefault project ka naam
.github/workflows/deploy-firebase.ymlpush par live channel deploy

Headers jo farq daalte hain

"headers": [
  { "source": "*/.@(css|js|jpg|png|svg)", "headers": [{ "key": "Cache-Control", "value": "public, max-age=604800" }] },
  { "source": "*/.@(html|json|xml)", "headers": [{ "key": "Cache-Control", "value": "public, max-age=300" }] }
]

Assets ko hafta bhar cache, HTML ko 5 minute — isi liye site fast bhi lagti hai aur update bhi foran dikhta hai.

CI me credentials

1. Firebase Console → Project settings → Service accounts → Generate new private key
2. GitHub repo → Settings → Secrets → FIREBASE_SERVICE_ACCOUNT = poora JSON
3. Workflow khud live channel par deploy kar dega

Preview channels (bonus)

Har pull request ke liye temporary URL:

firebase hosting:channel:deploy pr-12 --expires 7d

Client ko preview dikhana ho ya design compare karna ho — production ko chhue baghair.

Manual deploy

npm i -g firebase-tools
firebase login
firebase use mizanoraorg
firebase deploy --only hosting,firestore:rules
Rule: jo bhi deploy ho, source git me ho. Host badal sakta hai, history nahi.
