IPTV Reseller Suite v6.1.2 — Owner Se Client Tak Ka Safar

Architecture

admin panel   credits,      playlist,
pricing,      clients,      EPG, app

Har level ka apna panel hai — aur har level par wahi rules lagte hain: kaun kya dekh sakta hai, kitne devices, kab tak.

v6.1.2 me kya hai

  • Reseller registration + credits + clients (renew / suspend / delete)
  • Pricing engine + payment ledger
  • Key rotation (compromised key foran band)
  • M3U import, XMLTV EPG, Xtream Codes, MAG/Stalker
  • Signed playback URLs — link copy karke bahar nahi chalti
  • 183+ integration tests (imports, EPG, Xtream, playback, admin)
