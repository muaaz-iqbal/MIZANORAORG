Asaan Lang Se HTML Website — Web Compiler Kaise Kaam Karta Hai

Ek command, ek website

bash
asaan --web site.asaan -o site.html

Aur site.html browser me khul jati hai. Ye magic nahi — compiler hai.

Pipeline (4 stages)

site.asaan
   │  lexer      → tokens
   │  parser     → AST
   │  codegen    → HTML strings
   ▼
site.html
StageKaamExample
LexerCode ko chhote tokens me todnalikho → KEYWORD
ParserTokens se structure bananaagar x > 5 to → IfNode
CodegenAST se output bananaIfNode → <p>/text
RuntimeVariables, loops, functionsREPL me same

Language ka core

likho "Salaam duniya"
naam = lo "Aapka naam? "
agar naam == "Muaaz" to
    likho "Khush aamdeed, boss!"
warna
    likho "Salaam, " + naam
bas
  • agar / warna / bas — decisions
  • har i se 1 tak 10 to — loops
  • jabtak — while
  • kaam jama(a, b) wapis a + b bas — functions
  • koshish / pakro — try/catch

Errors bhi Urdu me

Line 4: "warna" se pehle "to" chahiye tha

Beginner ke liye ye farq huge hai — error message seekhne wala hota hai, daraane wala nahi.

Kyun ye kaam karta hai

Pakistan me programming ki pehli rukawat English hoti hai, logic nahi.
Asaan Lang pehle soch sikhati hai — phir Python asaan lagti hai.
