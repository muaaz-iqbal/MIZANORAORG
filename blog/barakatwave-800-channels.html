BarakatWave TV: 800 Channels, Ek Browser

Kya hai BarakatWave TV?

Pakistan aur India ke liye live TV + cinema platform:

  • 800 channels (news, sports, entertainment, regional)
  • IMDb-powered cinema — tt… id se poster, cast, episodes, 2000–2026
  • Multi-server relay failover — ek server mare to agla khud lag jata hai
  • Free Xtream server — Televizo, TiviMate, XCIPTV, VLC me chalta hai
  • PiP, quality/audio-track switching, playlists, favourites — privacy by default (browser me)

Failover ladder kaise kaam karti hai

source 1 (primary)  ──✗──▶  source 2  ──✗──▶  source 3  ──▶  user ko message: "abhi down"

Har attempt user ko dikhta hai — chup-chaap loading spinner nahi. Yahi trust banata hai.

4-video broadcast suite

Welcome intro → #EXT-X-DISCONTINUITY → live handoff → standby loop.
Sab kuch FFmpeg + GitHub Actions par, bina VPS.

Sabaq jo suspension ne diya

24/7 Actions workloads ne account suspend karwaya. Aaj design aisa hai:

  • Playout code ab portable hai (kisi bhi host par chal sakta hai)
  • Playlists aur config repo me hain, kisi ek account me nahi
  • Backup: git bundle + Drive
800 channels ka maza tab hai jab wo kabhi na rukein — architecture wahi guarantee deta hai.
