Naye Developers Ke Liye 5 Sabaq — Saste Phone Se Shuru

Sabaq 1 — Tool bahana nahi hota

Sab kuch saste phone par build aur test hua. Jo phone aapke paas hai, wohi aapka dev machine hai.

  • Editor: browser me hi (GitHub web editor, StackBlitz)
  • Deploy: free static hosts
  • Test: asli device, asli network speed

Sabaq 2 — Chhota ship karo, jaldi ship karo

Bara idea 3 mahine me nahi, chhota slice 3 din me. Feedback asli hota hai, imagination nahi.

GhalatSahi
"Poora app ready hone do""Ek page live karo, phir barhao"
"Perfect design""Kaam karta hua design"

Sabaq 3 — Backup pehle din se

Ek account suspend = 90 repos 404. Ye guzra hua waqt hai, aap ka future ho sakta hai.

git clone --mirror   → GitLab / Codeberg
git bundle create    → Google Drive
JSON export          → weekly

Sabaq 4 — English perfect nahi, logic perfect chahiye

Variable ka naam totalPrice ho ya total_qeemat — chalega. Lekin edge cases theek hone chahiye: khali input, slow network, double tap.

Sabaq 5 — Imaandari feature hai

Fake data, fake reviews, fake "guaranteed profit" — inki umar chhoti hoti hai. Honest product slow chalta hai, lekin rukta nahi.

"Unchi soch. Chhote qadam." — Kasur se, 2009 se, abhi tak.
